One word, first thought: **Snollygoster**. A shrewd, unprincipled politician, in a word that sounds as comic as it reads. The program writes that one fixed word, byte for byte, to `/output/entry.txt`.

## Run it

```sh
mkdir -p out
MAKEFUN_OUTPUT_DIR=out node --experimental-strip-types main.ts
cat out/entry.txt
```
